# Коран онлайн — quran.nurtech.dev

Сайт для чтения, изучения, прослушивания и заучивания Корана на русском языке.
Функциональный аналог quran-online.ru со своей чистой реализацией (без копирования чужого кода).

Стек: **Astro** (static / SSG), ванильный TypeScript для клиента. Часть экосистемы NurTech,
следует конвенциям статических сайтов (как aiengineer.nurtech.dev).

## Возможности (MVP)

- 114 сур, 6236 аятов: арабский текст (Усмани), перевод Кулиева, тафсир ас-Саади.
- Режим мусхафа (`/mushaf/1`): 604 QCF4-страницы, 15 строк на страницу, QCF-глифы,
  пословная разметка.
- Страницы: главная, сура (`/surah/1`, `/surah/1/saadi`, `/surah/1/kuliev`), аят (`/ayah/2/255`),
  короткая ссылка (`/2:255`), поиск, аудио, видео, скачать, инфо-страницы.
- Верхняя панель: быстрый переход (`2:255`, `ясин`, `18`), поиск, режимы отображения,
  выбор перевода/чтеца, настройки чтения, темы (светлая/тёмная/сепия/системная), закладки, «Продолжить».
- Аудиоплеер: play/pause, пред/след аят, повтор аята, повтор диапазона, скорость 0.75–1.5×.
- Поиск по русскому переводу с подсветкой и фильтрами.
- localStorage: тема, настройки, закладки, последнее место. Без регистрации.
- Горячие клавиши, RTL, мобильная версия, PWA-готовность (частично).

## Данные

Источник (vendored в `data/`): арабский Усмани + перевод Кулиева в структурированных JSON.
Тафсир ас-Саади пересобирается из `quran-online.ru/{s}/saadi` по сноскам `hint-{s}-{a}-{i}`,
потому что у spa5k `ru-tafseer-al-saddi` есть системный сдвиг привязки к аятам.
Аудио — EveryAyah (ссылки, не файлы).

`scripts/build-data.mjs` (запускается на `prebuild`/`predev`) генерит `public/data/`:
`index.json` (метаданные сур), `search-index.json` (русский текст для поиска), `reciters.json`.
Для режима мусхафа сборка берёт `quran-qcf4`: 604 JSON-страницы, `verses.json` и WOFF2-шрифты
QCF4. JSON-данные MIT; сами QCF-шрифты имеют отдельные ограничения и используются только
для коранического отображения.

## Разработка

```bash
npm install
npm run dev       # http://localhost:4321
npm run build     # -> dist/ (статический сайт, ~13.6k страниц)
npm run preview   # предпросмотр собранного
```

## Деплой

`quran.nurtech.dev` на VPS `85.239.36.234`. Разовая настройка (DNS/nginx/SSL) и деплой — см.
[ops/SETUP.md](ops/SETUP.md). Коротко: `bash ops/deploy.sh`.

## Структура

```
data/                 vendored датасет (quran/*.json, tafsir/*.json, index.json)
scripts/build-data.mjs генератор public/data/
src/lib/              доступ к данным (SSG), иконки
src/components/       TopBar, SurahView, Drawer, Player
src/layouts/Base.astro общий layout (SEO, темы, подключение клиента)
src/pages/            роуты
src/client/           app.ts (панель/плеер/закладки/хоткеи), search.ts, audio.ts
src/styles/global.css дизайн-система (темы, настройки чтения)
public/fonts/         арабские шрифты (Mushaf/Amiri/Naskh, свободные лицензии)
public/fonts/qcf4/    generated QCF4-шрифты из npm-пакета quran-qcf4
ops/                  deploy.sh, nginx-quran.conf, SETUP.md
```

Источники и лицензии указаны на `/about`.
