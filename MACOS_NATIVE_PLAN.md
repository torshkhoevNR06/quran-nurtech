# Quran.nurtech.dev → чисто нативный macOS

План переработки приложения так, чтобы на десктопе оно ощущалось как нативное
приложение Apple. Источник эталона — **EasyBot / NurCRM** (`funnel-saas`):
`MACOS_LIQUID_GLASS_SPEC.md` + токены `web/src/styles.css` + примитивы
`web/src/app/shared/ui/ui-foundation.css`. EasyBot на Taiga/Angular — мы переносим
**принципы и токены**, реализуя их на нашем ванильном CSS (Astro static).

---

## 0. Что уже есть в Quran и что не так

**Есть:** Liquid Glass база (`--glass-*`, backdrop-filter, амбиентные орбы),
нейтральная графитовая палитра, macOS-меню настроек (сегмент-контролы, слайдеры,
поп-ап, правые галочки), sticky-топбар, `content-visibility` для длинных сур.

**Не по канону (чинить):**
- Нет единых шкал `--sp-* / --radius-* / --fs-*` — размеры и отступы «на глаз»
  (сырые `22px`, `16px`, `clamp(...)`), поэтому плотность гуляет.
- Тени/радиусы местами сырые (`0 10px 28px…`, `16px`), не токены.
- Шрифт UI — Manrope. Нативный macOS хочет системный **SF Pro / -apple-system**
  для интерфейса (арабский/чтение — свои шрифты остаются).
- Стекло не разложено на слои-материалы (nav/sheet/popover/card) с честным
  `@supports` и `prefers-reduced-transparency` фолбэком — блюр местами «всегда».
- Десктоп-навигация — гамбургер+drawer. Нативный mac — **боковая колонка-source list**
  (список сур слева), а не выезжающая шторка.
- Иконки-глифы местами текстом (`→`, `✓`, `✕`); нужен единый SVG-набор (SF-стиль).
- Контролы кое-где крупные/на всю ширину («телефонный» вид).
- Нет `focus-visible` ring, `active:scale`, `tabular-nums`, `prefers-reduced-motion`.

## 1. Семь принципов (канон, адаптировано)

1. **Плотность, а не размер.** Компактные контролы: поля/кнопки ~28–32px на десктопе
   (не «на пол-экрана»). Короткие поля — по ширине смысла, не 100%.
2. **Стекло слоями.** Непрозрачный фон → `panel` → `card` (мягкое стекло) →
   `popover/sheet` (полный блюр). Блюр **только** под `@supports`, с фолбэком.
3. **Один акцент.** `--accent` (графит) — единственный акцент. Статусы — только
   `--good/--mid/--low`. Никаких вторых hex на заливках.
4. **Настоящие иконки.** Только SVG (SF-подобные), никаких текст-глифов в кнопках.
5. **Тише декор.** Без декоративных эмодзи; смысл — цветом/иконкой/текстом.
6. **Тёмная тема — первый класс.** Всё на токенах, ни одного голого `#hex/#fff`
   на залитых элементах (бери `--on-accent`).
7. **Системность.** SF-шрифт для UI, `focus-visible`-кольца, `active:scale(.96)`,
   `tabular-nums` для чисел, уважение `prefers-reduced-motion/-transparency`.

## Фаза 0 — Фундамент токенов  (0.5 дня)

Добавить в `:root` (и продублировать значения-зависимости в тёмной теме) единые
шкалы по образцу EasyBot:

```css
:root {
  /* отступы */
  --sp-1:4px; --sp-2:8px; --sp-3:12px; --sp-4:16px; --sp-5:20px; --sp-6:24px; --sp-8:32px; --sp-10:40px;
  /* радиусы */
  --radius-xs:6px; --radius-s:8px; --radius-sm:10px; --radius-md:12px; --radius-lg:16px; --radius-xl:20px; --radius-pill:999px;
  /* кегли (целые) */
  --fs-11:11px; --fs-12:12px; --fs-13:13px; --fs-14:14px; --fs-15:15px; --fs-16:16px;
  --fs-17:17px; --fs-18:18px; --fs-20:20px; --fs-22:22px; --fs-26:26px; --fs-30:30px; --fs-34:34px;
  /* тени */
  --shadow-card: 0 1px 3px rgba(0,0,0,.10);
  --shadow-pop: 0 12px 32px rgba(0,0,0,.18);
  /* линии/поверхности */
  --hairline: rgba(20,24,30,.08);
  --panel: <непрозрачная поверхность>;   /* уже есть --panel-bg */
  --panel-2: <вложенная поверхность>;
  /* статусы (пригодятся для «мекканская/мединская», ошибок) */
  --good:#3a9d6b; --mid:#c9973f; --low:#d4585f;
  /* системный шрифт интерфейса */
  --ui-sans: -apple-system, BlinkMacSystemFont, 'SF Pro Text', 'Segoe UI', system-ui, sans-serif;
}
:root[data-theme='dark']{ --hairline:rgba(255,255,255,.08); --shadow-card:0 1px 3px rgba(0,0,0,.3); --shadow-pop:0 14px 36px rgba(0,0,0,.45); }
```

- Завести `--knob/--seg-track/--seg-thumb` (уже есть) в эту же систему.
- **Не удалять** арабские/reading-шрифты (`--ar-font`, Mushaf) — они для аятов.
  `--ui-sans` — только для интерфейсной хромы (шапка, меню, кнопки, подписи).
- Убрать дублирующий второй `:root` («reader-first redesign») — свести в один.

**Выхлоп:** дальше все компоненты используют только токены — плотность станет ровной.

## Фаза 1 — Материалы стекла  (0.5 дня)

Формализовать 4 материала (по `ui-foundation.css`), блюр под `@supports`:

```css
--glass-blur: saturate(180%) blur(24px);
--glass-nav:   color-mix(in srgb, var(--bg) 62%, transparent);   /* топбар/тулбар */
--glass-sheet: color-mix(in srgb, var(--panel) 90%, transparent);/* drawer/лист */
--glass-pop:   color-mix(in srgb, var(--panel-2) 82%, transparent);/* меню/дропдаун */
--glass-card:  color-mix(in srgb, var(--panel) 90%, transparent);/* карточка аята */
--glass-edge:  inset 0 1px 0 rgba(255,255,255,.5);  /* верхний блик; в тёмной .16 */
```

- Классы-роли: `.mat-nav`, `.mat-sheet`, `.mat-pop`, `.mat-card` — задают bg + edge + shadow,
  блюр добавляется в `@supports (backdrop-filter)`.
- `@media (prefers-reduced-transparency: reduce)` → снять блюр, залить `--panel`.
- **Не блюрить** тяжёлый контент (лист чтения длинной суры) — только хрому/поповеры
  (перф: у нас уже была эта гоча с Аль-Бакарой).

## Фаза 2 — Плотность и типографика  (1 день)

- **UI-хрома → `--ui-sans`** (SF). Аяты/переводы — как есть.
- Перевести все интерфейсные размеры на `--fs-*`, отступы на `--sp-*`, радиусы/тени на токены.

- Заголовки: `letter-spacing:-.012em; font-weight:700` (Apple-подача).

## Фаза 4 — Экраны (по одному, под канон)  (2–3 дня)

Порядок — от «каркаса» к деталям:

1. **Тулбар (топбар).** Материал `mat-nav`, компактная высота, иконки SVG,
   `.icon-btn` единого размера, поиск-поле `--fs-13`. Активный сегмент видов —
   капсула. Разделители — `--hairline`.
2. **Десктоп-сайдбар (source list).** Самое «маковое»: слева постоянная колонка
   со списком сур (как Finder/Mail/Notes) вместо гамбургер-drawer. Строка суры:
   номер-бейдж, русское имя, аят-каунт; выбранная — accent-подсветка. На мобиле —
   прежний drawer как `mat-sheet`. Каркас: `grid: [sidebar] [reader]` на `≥1024px`.
3. **Читалка (страница суры).** Карточка аята → `.card` (мягкое стекло), плотные
   отступы `--sp-*`, экшены аята — `.icon-btn` в ряд, тафсир-тумблер причесать.
   Заголовок суры — крупный, но по токенам.
4. **Меню/поповеры** (перевод, чтец, закладки) → `mat-pop`, стиль как настройки.
5. **Плеер** → `mat-nav`/плавающая карточка, компактные транспорт-кнопки SVG,
   `tabular-nums` для таймингов, скруб-слайдер как range-примитив.
6. **Поиск** → нативное поле-«spotlight», результаты списком-`list-row`.
7. **Главная / инфо-страницы** → карточки `.surface`, секции `.section`.
8. **Редактор картинок** → уже модалка; привести кнопки/чипы к примитивам.

## Фаза 6 — Полировка «нативности»  (0.5 дня)

- `focus-visible` кольца везде (клавиатурная навигация как в macOS).
- `active { transform: scale(.96) }` на кнопках; поповеры — scale-in от якоря.

- `@media (prefers-reduced-motion)` — глушим анимации; `prefers-reduced-transparency`
  — снимаем блюр.
- Хоткеи (уже частично есть) — показать шпаргалку `?`, как в EasyBot.
- Скроллбары — тонкие overlay-стиля (уже в меню; распространить).

## Порядок и оценка

Фазы 0→1→2 (фундамент) делать подряд — они дают наибольший скачок «нативности»
малой кровью. Далее 3 (примитивы) → 4 (экраны, самый объёмный, сайдбар — ключевой) →
5→6 (иконки/полировка). Грубо **~6–8 человеко-дней**, но заметный эффект уже
после Фаз 0–2 (+сайдбар из Ф4). Катаем инкрементально, проверяя каждую фазу в
реальном браузере (свет/тёмная), деплой после зелёной сборки.
